# Algorithms and Data Structures

Collection of algorithm and data structure exercises from my computer science degree.

## Topics

- Recursion
- Searching and Sorting
- Data Structures (Stack, Queue, List)
- Generic List ADT — interface + static array-backed implementation
- Insertion Sort
- Binary Search

## How to run

Single-file exercise:

```bash
javac FileName.java
java FileName
```

Multi-file exercise (e.g. electoral-system):

```bash
cd electoral-system/src
javac *.java
java CandidateMain
```
